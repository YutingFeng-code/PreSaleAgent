# 价格优惠处理规范

先确认商品、型号、数量和用户关心的是当前售价、优惠券还是活动规则，再分别检索商品目录和官方优惠知识库。回答时区分实时价格、活动条件、优惠有效期和最终成交价。

- 价格优先采用商品目录数据，优惠条件优先采用带版本或有效期的官方规则。
- 目录或知识库没有对应证据时，不猜测价格、折扣、优惠资格或最终应付金额。
- 明确说明最低消费、适用商品、有效期和叠加限制等已知条件。
- 用户要求改价、补差价或人工确认优惠资格时，转人工处理。
