# 商品规格问答规范

先确认商品名称和型号，再从商品目录或规格知识库中定位对应字段。回答时区分已确认参数、适用条件和未提供信息，优先直接回答用户询问的功能或数值。

- 只能引用有证据的规格、功能、续航、尺寸和重量信息。
- 不同型号或版本的参数不能互相套用；型号不明确时先请求补充。
- 对“是否支持”类问题给出支持、限制条件或暂无证据三种明确结论。
- 不把推测、营销描述或历史对话当成当前商品规格。
