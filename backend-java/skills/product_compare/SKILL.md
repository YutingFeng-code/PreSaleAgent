# 商品对比处理规范

先确认用户要比较的商品、型号和关注维度，再使用商品目录和知识库证据进行对比。优先按价格、规格、核心功能、适用场景、库存和配送统一组织结果，明确每个维度的差异。

- 说明各商品更适合的人群和使用场景，不把推荐写成绝对结论。
- 证据缺失的维度标记为“暂无可核实信息”，不要用常识补全。
- 如果只有一个商品或型号信息不完整，只询问完成比较所必需的字段。
- 对比结束后给出选择建议、主要取舍和一个可行的备选方向。
