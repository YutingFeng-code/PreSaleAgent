# 库存配送处理规范

先确认商品、型号、数量和配送地点，再优先使用商品目录的实时库存与配送字段。明确区分现货状态、预计发货时间和预计到货时间，不把静态知识库说明当成实时承诺。

- 库存、发货和配送信息必须来自目录 API 或带有效期的明确证据。
- 目录不可用、查询为空或证据过期时，只能说明无法核实，不得承诺现货或到货日期。
- 多个商品或不同地区的时效需要分别说明，不能用一个结果覆盖全部商品。
- 用户要求锁库存、下单或修改配送时，转人工处理。
