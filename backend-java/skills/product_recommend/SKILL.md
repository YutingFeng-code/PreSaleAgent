# 商品推荐处理规范

先识别预算、使用场景、使用者或收礼对象、关注功能和限制条件，再检索商品目录与选购知识。推荐时说明选择依据、适用人群、可能取舍和备选方案。

- 当前需求优先于历史画像；历史画像只能调整表达方式，不能推断商品事实。
- 预算、场景或对象缺失时，最多询问完成推荐所需的关键字段。
- 推荐商品必须有目录或知识库依据；没有证据时只提供选购方法。
- 不使用“最好”“唯一适合”等绝对化结论，保留用户最终选择空间。
